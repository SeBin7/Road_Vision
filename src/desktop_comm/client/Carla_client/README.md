# CARLA 3-Channel 자율주행 AI 프로젝트

## 📌 개요
이 프로젝트는 **CARLA 시뮬레이터**를 활용하여 자율주행 AI 시스템을 구현한 프로젝트입니다.  
주요 기능은 다음과 같습니다:
- CARLA 환경에서 차량 및 RGB 카메라 생성
- 실시간 영상 수집 및 HUD 표시
- 엣지 서버를 통한 이미지 특징 추출
- GRU 기반 시퀀스 분류기 모델을 통한 도로 상태 추론
- 자율주행/수동 조작 전환, 날씨 변경, 차량 리스폰 기능 지원
- 모듈화 구조로 유지보수/확장 용이

---

## 🛠 주요 기능
- **실시간 차량 시점 HUD**: 속도, 현재 날씨, 예측 레이블, 신뢰도 표시
- **AI 추론**: 카메라 프레임을 엣지 서버에 전송해 특징 추출 후 GRU 모델로 도로 상태 분석
- **사용자 조작**:
  - `W/A/S/D`: 차량 수동 조작
  - `P`: 자율주행 모드 토글
  - `R`: 후진 모드 토글
  - `I`: 추론 기능 토글
  - `F`: 전체화면 토글
  - `1~8`: 날씨 변경
  - `N`: 차량 재생성
  - `ESC`: 종료

## ⚙️ 설치 및 실행 방법

### 1) 필수 환경
- Python 3.8 이상
- CARLA 시뮬레이터 (해당 버전 설치)
- PyTorch (CPU 또는 CUDA 버전)
- 주요 라이브러리: `pygame`, `numpy`, `pillow`, `requests`

### 2) 실행
1. **CARLA 서버** 실행
2. **엣지 서버**(특징 추출 서버) 실행
3. 메인 프로그램 실행: main.py

## 🔗 모델 & 서버 설정
`config.py`에 아래 항목을 환경에 맞게 수정하세요.

- **MODEL_PATH**: 학습된 GRU 모델 가중치 파일 경로
- **SERVER_URL**: 전체 추론 처리 서버 URL
- **EDGE_URL**: 특징 벡터 추출 전용 API 서버 URL

## 📌 참고 사항
- CPU에서만 추론하려면 `torch.load()` 호출 시 `map_location='cpu'` 및 `weights_only=True` 설정 권장
- 추론 서버 및 엣지 서버는 로컬 또는 네트워크 환경에서 사전에 실행되어 있어야 함
- 모듈 구조 덕분에 개별 기능만 따로 테스트 가능
